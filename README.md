# PCA Assignment

This project demonstrates the use of Principal Component Analysis (PCA) for dimensionality reduction.

## What I did
- Loaded and explored the dataset  
- Standardized the data  
- Applied PCA  
- Reduced the dataset to a few principal components  
- Visualized the results  

## Goal
To understand how PCA reduces dimensions while keeping most of the important information (variance).

## Tools used
- Python  
- Jupyter Notebook  
- NumPy, Pandas, Matplotlib, Scikit-learn  

## Notes
This was done as part of an assignment.
